# Liquid Handling Lab — Student Simulator

An independent, browser-based educational simulator for teaching liquid-handling workflows, worktable setup, disposable-tip handling, and basic script logic.

## Use

Once GitHub Pages is enabled, open the published website in a modern browser. No installation or backend is required.

## Limitations

This simulator is for instruction only. It does not connect to a physical liquid handler and must not be used to control laboratory equipment or validate a real instrument protocol.
